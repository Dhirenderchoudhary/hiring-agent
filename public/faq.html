Questions

Short answers. The rubric itself is on Algorithm.

What is this?

A page on top of HackerRank’s open-source hiring agent. You upload a PDF. It reads the text, checks a public GitHub profile only if one is printed on the resume, and returns a score.

Is this official HackerRank?

No. It runs their open-source agent. HackerRank does not operate this page and is not affiliated with it.

Do you keep the resume?

No. There is no account. The PDF is deleted after scoring.

Why doesn’t it start on drop?

Scoring calls a model and can take a minute or two. It waits until you press Run analysis.

What do the four numbers mean?

Open source is 35, self projects 30, production 25, technical skills 10. Those add to 100. Bonus can add up to 20. Deductions come off.

Does my college or GPA count?

No. Name, college, grades, and city do not move the score.

What if the resume has no GitHub link?

The agent still scores the PDF. It only reads GitHub when a profile is on the page, and only the public profile.

Why might a second run differ?

A model writes the evidence. A point can move. Read the bars and the lines under them, not only the total.

Where can I see a finished score?

Dhirender Choudhary, 97 / 100, with the four bars, bonus, strengths, and gaps.
